📚 Cẩm nang Học nhanh & Trả lời Bảo vệ Đồ án (DT063)

1. Bất biến cấu trúc (Invariants)
• dau is None ⇔ cuoi is None ⇔ n == 0
• Khi n > 0: dau.truoc is None và cuoi.ke is None
• Mọi cặp liên tiếp: u.ke == v ⇒ v.truoc == u
• Hệ quả: nguoc == list(reversed(xuoi))
2. Thứ tự gán con trỏ khi Thêm đầu
Khi danh sách khác rỗng (3 liên kết sửa):
(1) m.ke = L.dau
(2) L.dau.truoc = m
(3) L.dau = m
⚠️ Nếu gán (3) trước (2) sẽ mất tham chiếu tới đầu cũ!
3. Tách nút p đã biết trong O(1)
• Nhánh trước: if p.truoc is None: L.dau = p.ke else p.truoc.ke = p.ke
• Nhánh sau: if p.ke is None: L.cuoi = p.truoc else p.ke.truoc = p.truoc
• Luôn tốn đúng 2 liên kết sửa (kể cả xóa đầu, cuối hay nút duy nhất).
4. Tại sao Tìm O(n) nhưng Tách O(1)?
• tim_nut(x) phải duyệt tuần tự từ dau nên xét min(vị_trí, n) nút → O(n).
• Khi đã có nút p, nhờ con trỏ p.truoc, ta nối thẳng 2 hàng xóm của p mà không cần duyệt lại như DSLK đơn → O(1).
